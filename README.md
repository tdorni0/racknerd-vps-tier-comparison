## 便宜在哪，代价是什么

入门档的典型配置区间是 1 vCPU、512MB–2GB 内存、10–40GB SSD、1–3TB 月流量、100–1000Mbps 共享端口。RackNerd 的四档都在这个框架里，端口标 1Gbps，但这个数字是节点共享带宽，不是给你独享 1Gbps 跑满。

便宜的原因不神秘：vCPU、内存、磁盘 I/O 存在超售，节点上挤的邻居多；硬件多为上一代平台，批量采购摊薄成本；SLA 承诺偏松，宕机补偿有限；客服靠自助化和工单，人力成本低；年付提前回款，配合节日促销以价换量。

落到使用上，这些代价会变成三件具体的事：

- **持续高吞吐会被限速或按公平使用政策处理。** 短时间跑满带宽没问题，长时间满速下载、做中转或回源，就要看条款。
- **快照、自动备份、高防、额外 IPv4 大多要另外付钱。** RackNerd 的条款写得很清楚：VPS、独立服务器默认不含托管备份，官方不对数据完整性负责，建议自己保留离机备份。
- **晚高峰的国内访问速度不保证。** 这类机器走的是普通 BGP 线路，不是 CN2 GIA 或 AS9929 那类回国优化线。白天测试数字好看，晚上八点掉一半是常态。

## 拿到机器先做这五件事

年付之前，花半小时把这五项跑一遍，比看十篇测评有用。

1. **晚高峰测线路。** 晚上八九点跑 `mtr` 和 `traceroute` 到你的目标地区，看丢包和跳数。白天测出来的数字不代表晚高峰。
2. **测磁盘稳定性。** `fio`、`dd`、`ioping` 各跑一轮，看 IOPS 波动。超售严重的节点，磁盘延迟会忽高忽低。
3. **压 CPU 看掉频。** `stress-ng` 跑 10–30 分钟，观察频率和负载是否被压制。
4. **对带宽。** 用 `iperf3` 测实际吞吐，和标称的 1Gbps 比一比，心里有个数。
5. **先把安全配好。** 改 SSH 端口、禁用 root 直登、装 Fail2ban、配好异地备份，再往上放东西。

跑完这五项觉得可以，再考虑续费或者加配置。年付机器退不了，这半小时是唯一的验货窗口。

## 哪些需求不该买这个价位的机器

便宜 VPS 有明确的适用边界。以下场景不要用：

- 金融、支付类核心业务
- 要求 SLA 99.99% 以上的业务
